## 为什么学嵌入式

机器人工程的核心是"怎么让机器动起来"，嵌入式就是这中间的桥梁。从传感器采集信号，到控制器处理数据，再到驱动器执行动作——每一步都离不开嵌入式。

## 环境搭建

我用的工具链：

- **MCU**：STM32F767IGT6（机创赛就是用这颗芯片）
- **IDE**：Keil MDK-ARM（写代码 + 调试）
- **下载器**：ST-Link V2
- **辅助工具**：STM32CubeMX（引脚配置 + 时钟树生成）

## 第一课：GPIO 点灯

所有嵌入式的"Hello World"——让一个 LED 闪烁。

```c
// 初始化 GPIO
HAL_GPIO_WritePin(GPIOB, GPIO_PIN_0, GPIO_PIN_SET);
HAL_Delay(500);
HAL_GPIO_WritePin(GPIOB, GPIO_PIN_0, GPIO_PIN_RESET);
HAL_Delay(500);
```

别小看这几行代码，它让你理解了 GPIO 输出、时钟配置、HAL 库的调用方式。

## 第二课：定时器

点亮 LED 之后，用定时器实现精确的 PWM 输出——控制舵机角度、电机转速全靠它。

- 定时器配置：分频系数、自动重装载值、计数模式
- PWM 输出：占空比控制 LED 亮度 / 舵机位置
- 中断处理：定时器溢出中断，处理周期性任务

## 第三课：串口通信

UART 是最简单的嵌入式通信方式。通过串口把 STM32 的数据发到电脑上位机：

- 波特率、数据位、停止位、校验位配置
- printf 重定向到串口
- 中断接收 + 环形缓冲区

## 踩过的坑

- 时钟配置错了，整个系统频率不对——CubeMX 生成的代码也要检查一遍
- 中断优先级没设好，两个中断互相打架
- ST-Link 下载时偶尔抽风，拔了重插就好

## 学习路径建议

GPIO → 定时器/PWM → 串口 → I2C/SPI → ADC → DMA → RTOS。别跳过基础直接上 RTOS，不然你会回来补课的。
